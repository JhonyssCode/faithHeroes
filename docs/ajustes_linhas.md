# Ajustes editoriais de comprimento

Revisão manual na continuação integral: as seguintes redações substituem as linhas longas; o verificador apenas aponta avisos.

- 'Busque os quatro\nfragmentos do rolo.' → 'Busque os quatro\npedaços do rolo.'
- 'Cuide dos animais.\nA chuva vai chegar.' → 'Cuide dos animais.\nA chuva vem aí.'
- 'Tua palavra é luz\npara o meu caminho.\nSl 119:105' → 'Tua palavra é luz\npara meu caminho.\nSl 119:105'
- 'Um tamborim para\nacompanhar o louvor.' → 'Um tamborim\npara o louvor.'
- 'Cada fragmento\nconta uma história.' → 'Cada fragmento\nconta uma\nhistória.'
- Aquele homem / está olhando o quê? → Aquele homem / olha para onde?
